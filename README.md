# Job Portal App

This is a full-stack job portal web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). It allows users to search and apply for jobs, while recruiters can post and manage job listings.

## Features
- User authentication and authorization
- Job search and filters
- Company dashboard to manage jobs
